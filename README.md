## 💡기획 의도💡
  - 본 프로젝트는 메이플스토리의 옥션 시스템을 모방한 웹 애플리케이션을 구현하여,
    실제 온라인 거래소의 작동 원리를 학습하고 웹 개발 기술을 연습하는 데 그 목적이 있습니다.
    사용자는 아이템을 등록하고, 검색하고, 구매하는 과정을 통해 거래 시스템의 전반적인 흐름을 경험할 수 있습니다.
